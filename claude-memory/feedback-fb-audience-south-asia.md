All content for the FB comedy page must target the whole South Asian audience (Pakistan, India, Bangladesh, diaspora), not one country.

**Why:** user said so on 2026-10-18; insights showed India 83%, Pakistan 11%, Bangladesh/Nepal ~5%.
**How to apply:** visual comedy that lands without words; Roman Hindi/Urdu subtitle + small English line; simple shared vocabulary; universal topics (shaadi, chai, relatives, exams, salary, food, weather); never politics, religion, India-vs-Pakistan, country stereotypes or country-specific currency/places; hashtags mix #DesiComedy #DesiLife #SouthAsianComedy #DesiFamily.
