SkyTrack: a free, Flightradar24-style live flight tracker.
- Live: https://flight-tracker-bice.vercel.app
- Repo: https://github.com/gulraiznoman/flight-tracker
- Local dir: `C:\Users\BiM Pro -057\flight-tracker`

Stack: plain HTML/CSS/ES-module JS + Leaflet 1.9 (CDN) frontend; Node/Express `server.js` locally (port 3000) + Vercel serverless functions in `api/` in prod. $0 budget, no API keys.

Data (all free): live positions = airplanes.live + adsb.fi merged (`api/flights.js`, viewport-tiled); history = adsb.lol `/data/traces/xx/trace_full_<hex>.json` (`api/trace.js`; airplanes.live trace store returns 403 to everyone since Oct 2026, kept as fallback; adsb.lol is ODbL, credit shown in map attribution); routes/airline = adsbdb (`api/search.js`); photos = planespotters; airport weather (METAR) = aviationweather.gov (`api/metar.js`, no key, 5min cache). GOTCHA (Aug 2026): airplanes.live GATED its global `/v2/callsign/` and `/v2/hex/` endpoints (returns `{"error":"please contact us..."}`); only `/v2/point/` still works there. So global flight SEARCH (`api/search.js`) uses adsb.fi + adsb.lol `/v2/callsign/{cs}`, which return aircraft under the `"ac"` key (NOT `"aircraft"`). Oceanic flights (mid-Atlantic etc.) still won't be found: free ADS-B has no receivers there.

Airport info panel: clicking an airport opens a panel with identity (name, IATA/ICAO, city, country, elevation), live METAR weather (temp/wind/visibility/pressure/flight-category), and nearby live traffic (departures/arrivals/on-ground) inferred from ADS-B climb/descent within 40nm. Airport records live in `public/data/airports.json` (rebuilt from OurAirports, 4589 entries, fields `{c:display-code, i:ICAO, n:name, m:city, co:iso-country, e:elev-ft, y:lat, x:lon, s:size}`). Marker clicks wired via `createMap({onAirportClick})` in map.js -> `showAirport()` in main.js. Basemaps (layers menu, kept to 3): Modern (Esri Ocean/World_Ocean_Base, default, maxNativeZoom 10; CARTO started requiring an API key Oct 2026, all its styles return an 'API KEY REQUIRED' tile) / Terrain (Esri shaded relief) / Satellite (Esri imagery). City labels drawn from a 34k-city GeoNames set (`public/data/cities.json`) with FR24-style collision de-cluttering; airports are control-tower icons.

KEY CONSTRAINT: free ADS-B coverage over Central/South Asia is patchy, so trace history is often partial, stale, or the previous inbound leg — the root cause of nearly every "trail looks wrong" report. FR24 uses PAID Google Maps + satellite ADS-B; we cannot. The real fix is a paid data source (only the `api/` data layer would change). Current trail logic (`public/js/trail.js`) draws solid where genuinely tracked, dashed where estimated, and runs from the departure airport (from route, or inferred as nearest big airport when climbing with no route). Also has an opt-in synthesized aviation-ambience feature (`public/js/ambience.js`, Web Audio, phase-aware with a takeoff spool-up). See [[feedback-skytrack-work]] and [[reference-skytrack-deploy]].
