Keep Inflectiv copy plain and short: simple words, short graphic headings, short captions. The user repeatedly cut longer or more literary drafts.

No-narwhal graphic briefs must be concrete to Inflectiv's product (a dataset card with title, records, preview answer, price per query, scores), never abstract. The designer renders briefs literally: "the same listing card shown cluttered and clear" came back as two real-estate house listings, which the user called dumb.

**Why:** vague copy and vague briefs both failed review.
**How to apply:** write each no-narwhal brief so it cannot be mistaken for another industry, and tie it to the post's specific points. See [[project-inflectiv-socials]].
