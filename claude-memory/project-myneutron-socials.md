myNeutron is Vanar Chain's AI memory layer (support email is developers@vanarchain.com). Saved items are **Seeds**, which auto-group into **Bundles**. Chrome extension plus MCP. Live integrations as of Oct 2026: ChatGPT, Claude, Gemini, **Cursor via MCP**, **Gmail**, **Google Drive**. Mobile QuickSave was still listed as "coming" in Oct 2026, so verify before writing content around it.

**Plan files** live in `Downloads/withcontrol and myNeutron content plan Aug-Sept 2026/`, named `myNeutron <Month> 2026 Content Plan v<N>.xlsx`. Versioned, never overwritten (see [[feedback-versioned-deliverables]]).

**Sheet structure** copies the WithControl plans: tabs for Posts / Threads / Blogs / Schedule / Rules.
- Posts columns: Ref, Title, Angle, CTA type, Caption (X + LinkedIn), Graphic heading, Visual medium, Visual brief, Chars, Status
- Threads: one row per tweet, graphic brief only on the main-tweet row
- Status starts as "to design"

Plans written so far: September 2026 (15 posts, 5 threads, 2 blogs, docx), October 2026 v1 (12 posts), November 2026 v2 (10 posts, 3 threads, 2 blogs). Check the Angle column across all of them before writing new posts, since the recurring failure mode is restating "your AI forgets you" in a new costume.

Site fetching: myneutron.ai sometimes fails on SSL and x.com returns 402. `https://r.jina.ai/<url>` worked as a fallback for the X profile.
